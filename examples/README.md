# Examples

This directory will contain sample input documents and expected output artifacts for `vidts`.

## Planned Examples

- **Sample Short Comic / Manhwa PDF**: Demonstrating visual document detection and panel pacing.
- **Sample Educational Paper / Textbook Excerpt**: Demonstrating structured academic concept recap and sectioning.
- **Sample General Document**: Demonstrating generic single-video narration.

## Running on an Example

Once a sample PDF (e.g., `examples/sample_document.pdf`) is placed in this folder:

```bash
python -m app.main examples/sample_document.pdf
```
